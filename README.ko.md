# mermark

**[English README](./README.md)**

로컬 문서를 빠르게 읽고 고치는 데스크톱 앱. 옵시디언식 라이브 프리뷰가 붙은 마크다운
편집기에 Mermaid 다이어그램과 수식이 들어가고, PDF·EPUB·오피스 문서·한글(HWP)·SQLite를
여는 뷰어가 기본으로 들어 있다. Tauri 2 + CodeMirror 6 기반이라 콜드 스타트가 1초가 채
안 걸리고, 파일은 계속 디스크 위의 평범한 파일로 남는다.

리더 모드로 열리고, `⌘E`로 편집 모드에 들어가면 입력이 잦아드는 대로 파일에 바로 저장된다.

```bash
mermark notes.md
```

## 설치

**[Releases](https://github.com/wis-graph/mermark/releases/latest)** 에서 받는다.

| 플랫폼 | 파일 |
|---|---|
| macOS (애플 실리콘) | `mermark_<버전>_aarch64.dmg` — 서명·공증 완료 |
| Windows (x64) | `mermark_<버전>_x64-setup.exe` |

업데이트는 앱이 알아서 한다. 실행 시 조용히 확인하고, 새 버전이 있으면 상태바에 업데이트
버튼이 뜬다. 내려받으면 자동으로 설치·재시작하는데, **재시작 직전에 저장 대기 중인 편집을
먼저 확정한다** — 그게 실패하면 재시작을 멈춘다. 편집을 버리면서 재시작하는 경로는 없다.

### `mermark` 명령어

**macOS / Linux** — PATH에 래퍼 스크립트를 설치한다(심볼릭 링크로 걸면 CLI로 띄운
인스턴스의 앱 내 업데이터가 깨진다):

```bash
./scripts/install-cli.sh                 # /usr/local/bin/mermark 에 설치
./scripts/install-cli.sh ~/bin/mermark   # 다른 위치로
```

**Windows** — `src-tauri\target\release\` 를 `PATH`에 추가한 뒤 `mermark file.md`.

## 무엇을 하나

### 치는 대로 렌더되는 마크다운

- **라이브 프리뷰** — 굵게·기울임·취소선·인라인 코드가 문법 기호를 감춘 채 렌더되고,
  커서가 그 안으로 들어가면 다시 원문이 드러난다.
- **GFM** — 표는 실제 HTML 그리드로, 체크박스는 누를 수 있는 체크박스로, 코드 펜스는
  문법 강조까지.
- **Mermaid** 다이어그램은 확대·이동된다. 더블클릭으로 확대 토글, `Ctrl`/`⌘`+휠로 커서
  쪽으로 확대, 드래그로 이동. 문법 오류가 나면 블록을 비우지 않고 원문으로 되돌린다.
- **수식**은 KaTeX로 — 인라인 `$…$`, 블록 `$$…$$`. 코드 블록 안의 `$`는 건드리지 않는다.
- **콜아웃**(`> [!note]`, `[!warning]`, `[!danger]`)은 색이 들어간 박스로, **각주**는
  위첨자와 흐린 정의로.
- **이미지** — 로컬(파일 기준 상대경로로 찾고, 없으면 그 문서가 속한 볼트 안에서 이름으로
  검색)과 원격 모두.

### 볼트 밖으로 새지 않는 링크

- **위키링크** `[[대상]]` / `[[대상|별칭]]` — 파일이 있으면 현재 창에서 열고, 없으면
  취소선으로 표시한다.
- **상대 문서 링크** `[라벨](./note.md)` — 심볼릭 링크까지 풀어 본 뒤에도 볼트 안에
  머무를 때만 열린다. 절대경로·`..` 탈출·모르는 스킴은 조용히 열거나 만들지 않고 **이유를
  보여주며 거절**한다.
- **이미지 첨부** — 이미지를 고르면 `![[이름.확장자]]` 로 삽입된다. 이미 볼트 안이면
  복사하지 않고, 밖이면 `.attachments/` 로 원자적으로 복사하되 기존 파일을 덮어쓰지 않는다.

### 마크다운이 아닌 파일용 뷰어

마크다운이 아닌 파일은 에디터 옆 풀페인 뷰어로 열린다. 보고 있던 문서는 뒤에서 상태와
스크롤 위치를 그대로 유지한다.

| 형식 | 비고 |
|---|---|
| **PDF** | 페이지 렌더링 + 확대 |
| **EPUB** | zip에서 항목별로 바로 꺼내 읽는다(임시 폴더에 풀지 않음) |
| **워드** (`.docx`) | |
| **엑셀** (`.xlsx`, `.xls`, `.csv`) | 시트 탭 |
| **한글** (`.hwp`, `.hwpx`) | 네이티브 파싱 + 페이지별 SVG 렌더 |
| **SQLite** (`.sqlite`, `.db`, `.db3`) | 페이지 단위로 디스크에서 읽어 수 GB짜리도 즉시 열린다 |
| **HTML** | 자바스크립트 실행 옵션(열 때마다 새로 발급되는 토큰 오리진으로 격리) |
| **이미지** | |

터미널에서 `mermark report.pdf` 도 된다 — CLI가 탐색기와 같은 뷰어 레지스트리에 경로를
넘긴다.

### 워크스페이스·볼트·탐색기

- 폴더를 **볼트**로 등록하고, **워크스페이스**로 묶고, 문서는 **탭**으로 연다.
- **파일 탐색기**(`⌘B`)는 레이지 트리다. 폴더는 한 단계씩 읽고, 숨김 파일은 토글이며,
  `⌘`/`Ctrl`+클릭은 새 창으로 연다.
- **"내 컴퓨터"** — 파일시스템 루트에서 `..` 를 누르면 드라이브 목록이 나온다(윈도우의
  C:·D:, 맥의 `/` 와 마운트된 볼륨). 하나를 고르면 그 드라이브로 들어간다.
- **파일 우클릭** — 기본 브라우저/미리보기/기본 앱으로 열기, 새 창에서 열기, Finder에서
  보기, 경로 복사.
- **이름으로 파일 찾기**는 `⌘⇧F`(VS Code `⌘P` 식 퍼지 검색). 최근 문서와 즐겨찾기는
  각자의 패널에 있다.

### 원격 볼트

다른 기기의 볼트를 읽는다 — 맥북에서 데스크톱의 문서를 보는 식으로.
[Tailscale](https://tailscale.com) 위에서 동작하고, 쓰지 않는 사람을 위해 `ssh -L` 터널
폴백이 있다.

- **읽기 전용이고, 명시적으로 공유한 것만.** 호스트는 체크한 볼트만 내주고, 모든 요청은
  디스크에 닿기 전에 2단 봉쇄(어휘적 경로 해석 → 심볼릭 링크 재검증)를 통과한다.
- **페어링은 6자리 코드**를 한 번 입력하는 것으로 끝나고, 그 자리에서 장기 기기 토큰으로
  교환된다. **토큰은 웹뷰에 절대 노출되지 않는다** — 커맨드는 호스트와 볼트 이름만
  들고 가고, 토큰은 Rust가 찾아 쓴다.
- 마크다운·이미지·PDF·워드·엑셀·HTML이 원격에서도 열린다. 연결이 끊기면 볼트 행에 다시
  시도 버튼이 뜨고, 호스트가 돌아오면 배지가 스스로 갱신된다.

### 작업을 잃지 않는 편집

- `⌘E` 로 리더/편집 모드를 오간다. 편집은 디바운스 저장.
- 쓰기는 **원자적**이다(임시 파일 + rename) — 반쯤 쓰인 파일이 남지 않는다.
- 연 뒤에 디스크에서 파일이 바뀌었으면 저장을 **보류**하고 **강제 저장** 탈출구를 준다.
  버퍼가 조용히 덮어써지는 일은 없고, 복구된 내용은 `.mermark-recovered` 파일로 남는다.
- 열어 둔 파일이 밖에서 수정되면 와처가 감지해 다시 읽어들인다.

### 테마와 타이포그래피

OS의 라이트/다크 설정을 따르되 수동 토글이 있고, 빌트인 프리셋 3종(다크·라이트·클로드)과
테마 편집기가 있다. 편집기에서는 미리보기 안의 요소를 **클릭해서** 지금 무슨 색을 바꾸는지
고른다. 본문 너비, 글꼴(Pretendard·Inter·Georgia·Paperlogy), 제목 글꼴은 모두 설정
항목이고, 본문 너비 슬라이더는 푸터에 있어 드래그 한 번으로 조절된다.

## 창이 열리는 규칙

평범한 `mermark file.md` 는 **마지막으로 포커스됐던 mermark 창을 재사용한다**. 새 창을
띄우는 건 두 가지 명시적 제스처뿐이다.

- `mermark -`(표준입력)와 `mermark --right`(화면 오른쪽 절반)는 독립 프로세스로 뜬다
- 탐색기·파일 찾기에서의 `⌘`/`Ctrl`+클릭 또는 `⌘Enter`

그 외 위키링크·로컬 문서 링크·최근 문서·즐겨찾기는 전부 현재 창에서 열린다.

없는 경로는 만들지 않고 오류다. `mermark 없는파일.md` 는
`mermark: 없는파일.md does not exist.` 를 출력하고 종료한다.

## 소스에서 빌드

Node와 Rust(cargo) 툴체인이 필요하다.

```bash
npm install
npm run tauri dev -- path/to/note.md   # 개발 실행(파일 인자 포함)
npm run tauri build                    # 로컬 빌드 — 아래 주의
```

산출물은 `src-tauri/target/release/mermark` 와 플랫폼 번들.

> **배포는 `scripts/release.sh` 가 소유한다.** 빌드·서명·공증·업로드·`updater.json`
> 기록까지 게이트를 걸어 그 스크립트가 다 한다. 배포용으로 `npm run tauri build` 를 직접
>쓰면 셸 환경의 `TAURI_SIGNING_PRIVATE_KEY` 로 업데이터가 서명돼 **기존 사용자 전원의
> 자동 업데이트가 깨진다.**

### 브라우저 모드

```bash
npm run dev:browser
```

Tauri 백엔드가 목으로 대체되고 내장 픽스처 문서(`src/mocks/tauri-core.ts` 의 `SAMPLE`)가
로드된다. CDP 골든 스크립트가 측정하는 게 이 픽스처이고, 모든 렌더러를 한 번씩 거친다.

### 테스트

```bash
npm test                     # vitest: 순수 리졸버 + 에디터 전체 렌더 스모크
npx tsc --noEmit             # 타입
cd src-tauri && cargo test   # 백엔드
```

스모크 테스트는 기능이 빽빽한 문서 위에 에디터 전체를 마운트해 예외 없이 렌더되는지 본다 —
CodeMirror 데코레이션 회귀(블록 데코레이션은 `ViewPlugin` 이 아니라 `StateField` 에서
나와야 한다)를 막는 장치다.

## 범위

문서를 읽고 고치는 데 집중한 앱이지, 범용 파일 관리자가 아니다. 렌더러는 CodeMirror 6
기반이고 옵시디언식 라이브 프리뷰가 그 위에 얹혀 있다.

계층별 전체 기능 목록은 [`docs/FEATURES.md`](./docs/FEATURES.md), 설계 기록은
`docs/design/` 와 `docs/superpowers/specs/` 에 있다.
